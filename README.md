# 💳 ההטבות שלנו — מערכת פרטית

בוט טלגרם ששואלים אותו בשפה חופשית "קנייה בפוקס ב-400 שקל" ומקבלים
מאיפה הכי כדאי לנצל, ומאחוריו סורק שנכנס למועדונים ומביא את ההטבות
ואת המצב האישי.

**הכל פרטי.** אין אתר ציבורי, אין קישור לשתף, והמאגר הזה פרטי. עונים
רק שני מזהי שיחה מאושרים בטלגרם.

```
טלגרם ← אריק ואשתו (נייד)
   ↕
Supabase (חינם, פרטי)              GitHub Actions (חינם, פרטי)
├── Postgres: הטבות + מצב אישי  ←── Playwright + סיסמאות ב-Secrets
└── Edge Function: הבוט               └── ממסר OTP דרך טלגרם
```

---

## מה צריך להקים — פעם אחת

הסדר חשוב: **שלב 1 ושלב 2 לפני שסוד ראשון נכנס למערכת.**

### 1. להחליף סיסמאות במועדונים

לפני הכל. סיסמה ייחודית לכל מועדון, שאינה בשימוש בשום מקום אחר.
המערכת תשמור אותן ב-GitHub Secrets, ולא כדאי שסיסמה שנשמרת אצל צד
שלישי תהיה גם הסיסמה של הדואר.

### 2. להפוך את המאגר לפרטי

GitHub ← Settings ← למטה, Danger Zone ← **Change repository visibility**
← Private.

באותו מסך, מוחקים גם את ענף `gh-pages` (Settings ← Branches, או
לשונית Branches ← פח האשפה ליד `gh-pages`). ה-workflow שפרסם אותו
כבר נמחק, אבל הענף עצמו נשאר וצריך הסרה ידנית.

### 3. בוט טלגרם

בטלגרם, `@BotFather` ← `/newbot` ← שם ← שם משתמש. הוא יחזיר טוקן.

כדי לדעת מהו מזהה השיחה שלך ושל אשתך: אחרי שהבוט יעלה, כל אחד שולח
לו הודעה, והוא יחזיר "אין לך הרשאה" יחד עם המזהה. את שני המזהים
מכניסים לטבלה `allowed_users`.

### 4. פרויקט Supabase

[supabase.com](https://supabase.com) ← New project (התוכנית החינמית
מספיקה) ← SQL Editor ← מדביקים את `supabase/schema.sql` ← Run.

מ-Settings ← API לוקחים את `Project URL` ואת `service_role key`.

> `service_role` עוקף הרשאות. הוא חי רק ב-Secrets וב-Edge Function,
> ולעולם לא בדפדפן.

### 5. פריסת הבוט

```bash
node supabase/functions/bot/build.js
supabase functions deploy bot --no-verify-jwt
```

ואז מחברים את הבוט לפונקציה:

```bash
curl "https://api.telegram.org/bot<טוקן>/setWebhook" \
  -d "url=https://<פרויקט>.supabase.co/functions/v1/bot" \
  -d "secret_token=<סוד שאתם ממציאים>"
```

### 6. סודות ב-GitHub

Settings ← Secrets and variables ← Actions ← New repository secret.

| סוד | מה זה |
|---|---|
| `SUPABASE_URL` | כתובת הפרויקט |
| `SUPABASE_SERVICE_ROLE_KEY` | המפתח מ-Supabase |
| `SESSION_KEY` | מחרוזת אקראית שאתם ממציאים, 16 תווים ומעלה. מצפינה את העוגיות |
| `TELEGRAM_BOT_TOKEN` | הטוקן מ-BotFather |
| `TELEGRAM_CHAT_IDS` | שני המזהים, מופרדים בפסיק |
| `<מועדון>_USER` / `<מועדון>_PASSWORD` | לכל מועדון שדורש התחברות |

שמות משתני הסביבה של כל מועדון רשומים ב-`scraper/clubs/*.json`.

**לבנקים אין סוד ואין צורך בו.** `discount_bank`, `onezero` ו-
`discount_green_wallet` מוגדרים `requiresLogin: false` — המערכת אוספת
מהם הטבות מהעמוד הציבורי ואינה מתחברת לחשבון, לפי בקשה מפורשת. יש
בדיקה שנועלת את זה.

## איך זה עובד ביום-יום

שולחים לבוט שאלה. `/status` מראה נקודות ודרגות, `/scan` מפעיל סריקה
עכשיו (יש גם סריקה שבועית אוטומטית), `/install` נותן את תוסף הגיבוי.

**כשמגיע קוד אימות:** הסורק שולח הודעה בטלגרם, מעתיקים את הקוד
מה-SMS ושולחים לבוט. הסורק ממשיך לבד. בזכות שמירת העוגיות זה קורה
בערך פעם בחודש ולא בכל סריקה.

## כשמועדון לא נסרק

זה יקרה, ולא בגלל תקלה: אתרי המועדונים חסומים מהסביבה שבה נבנתה
המערכת, ולכן אי אפשר היה לכתוב בוררים מדויקים מראש. `login.js` מנחש
לבד לפי סוג השדה — מה שעובד ברוב האתרים — וההתאמה לכל מועדון נעשית
אחרי הריצה הראשונה.

1. Actions ← הריצה האחרונה ← קוראים איזה מועדון נכשל ולמה
2. פותחים את האתר, לחיצה ימנית על השדה שנכשל ← "בדיקה" ← Copy selector
3. מדביקים ל-`scraper/clubs/<מועדון>.json`:
   ```json
   "selectors": { "otp": "#verification-code-input" }
   ```

הלוג בטוח לשיתוף — כל ערך שמקורו בסוד מוחלף שם ב-`***`, וזה מכוסה
בבדיקה שנכשלת אם סיסמה דלפה.

## פיתוח

```bash
npm ci
npm run test:unit   # מהיר, בלי דפדפן
npm test            # הכל, כולל סריקה מקצה לקצה (~2 דקות)
npm run build       # מרענן את העותקים המיוצרים
```

299 בדיקות בשש סוויטות. שתי בדיקות שומרות על העיקרון המרכזי:

- **זהות תשובות** — אותה שאלה למנוע ולבוט חייבת להחזיר אותה תשובה.
  הבוט אינו מנוע שני, הוא עוטף את `benefits/engine.js`.
- **אי-דליפה** — סיסמה מדומה עוברת בזרימה שנכשלת, והבדיקה נופלת אם
  היא מופיעה ולו בשורת לוג אחת.

| תיקייה | מה יש בה |
|---|---|
| `benefits/` | המנוע, מאגר ההטבות, הממשק הגרפי (מקומי) ותוסף הגיבוי |
| `scraper/` | התחברות, ממסר OTP, הצפנת עוגיות, מיסוך לוגים, תצורת מועדונים |
| `supabase/` | הסכימה והבוט |
| `test/` | הבדיקות ואתרי הדמה |

## מה שכדאי לדעת

- **דקות Actions** — 2,000 בחודש בתוכנית החינמית. סריקה שבועית של 13
  מועדונים צורכת כ-60, כלומר 3%.
- **Supabase חינמי נכבה אחרי שבוע ללא שימוש** — התזמון השבועי מעיר
  אותו ממילא.
- **תקנון המועדונים** — רובם אוסרים גישה אוטומטית. הסיכון קיים בכל
  סביבת ריצה ואינו ייחודי ל-Actions.
- **כל ההטבות שנסרקות נכנסות כ"לאימות"** — הזיהוי הוא ניחוש מושכל
  מטקסט חופשי. הבוט מסמן זאת בתשובה.
